Lock Tab Options

When a tab is locked, F5 / Ctrl+R / Cmd+R reloads without asking, and the tab stays locked. For unattended refresh, use the extension's Auto-refresh tab menu instead (see below).

Auto-refresh

Right-click the Lock Tab toolbar icon on any tab and choose Auto-refresh tab to reload it every 1–60 minutes. A refreshing tab shows a ↻ badge on the toolbar icon, and hovering the icon always states that tab's lock and refresh state.

  • Refreshes never ask for confirmation, and the tab stays locked.
  • Refresh is per-tab and independent of locking; turn it Off from the same menu. It is cleared when the tab closes or the browser restarts.
  • Other timer extensions that reload the page themselves will still trigger the confirmation on a locked tab — Chrome gives the extension no way to tell their reloads apart from closing the tab. Use the built-in menu above for unattended refresh.
